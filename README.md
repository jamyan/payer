# Платёжник

Платёжник — личный журнал регулярных расходов для одного владельца. Он помогает вести подписки, аренду, коммунальные и другие обязательные платежи. Начисления, оплаты и остатки доступны в веб-интерфейсе и Telegram Mini App. Бот отправляет напоминания, принимает записи об оплатах и выдаёт одноразовый код для входа в браузере. Банковских интеграций и переводов в приложении нет.

## Возможности

- Повторение через заданное число дней, недель, месяцев или лет. Начисления формируются на 90 дней вперёд, с учётом длины месяца и високосных лет.
- Фиксированные и переменные суммы, версии тарифов, перенос срока и частичные оплаты. Приложение проверяет сумму остатка перед записью.
- Исправление суммы и даты внесённой оплаты с обязательной причиной и сохранением исходной записи. Нулевая сумма отменяет отметку об оплате. Повтор запроса с тем же ключом идемпотентности не создаёт вторую запись.
- Архивирование и восстановление обязательств с новой даты. Ранее внесённые оплаты и история сохраняются.
- Итоги по срокам начислений, фактически внесённые суммы по датам оплат и остатки по старым долгам. Фильтры и поиск в веб-интерфейсе.
- Напоминания в 11:00 по Иркутску за 3 дня, за день и в день срока. Валюта — RUB, часовой пояс приложения — `Asia/Irkutsk`.
- Команды бота `/add` и `/pay` ведут через создание обязательства и запись оплаты. `/remaining`, `/overdue`, `/next` и `/summary` показывают остатки и итоги. `/login` выдаёт одноразовый код на 5 минут, `/logout` завершает браузерные сессии.

## Как устроено приложение

| Компонент | Назначение |
| --- | --- |
| FastAPI + Uvicorn | API, авторизация, HTML/CSS и JavaScript. Отдельная сборка фронтенда не требуется. |
| PostgreSQL 17, SQLAlchemy и Alembic | Начисления, оплаты, история, сессии, очередь бота и миграции схемы. |
| Worker | Генерация начислений и отправка напоминаний. |
| Telegram-бот | Диалоги в личном чате владельца, вход в Mini App и браузерные коды. Получает обновления через polling. |
| Caddy или Nginx Proxy Manager | HTTPS и маршрутизация к API в production. |

В Mini App сервер проверяет подпись Telegram и ID владельца. Обычный браузер обменивает код бота на защищённую cookie-сессию. При локальном запуске можно войти по отдельному токену без Telegram.

Код приложения — в `backend/app/`, миграции — в `backend/alembic/`, тесты — в `backend/tests/` и `frontend-tests.mjs`. Значки и сведения об источниках описаны в [ICONS.md](ICONS.md).

## Локальный запуск

Понадобятся Docker и Compose v2. Скопируй `.env.example` в `.env`. Сгенерируй разные значения для `POSTGRES_PASSWORD` и `LOCAL_API_TOKEN`, например дважды выполни `python -c "import secrets; print(secrets.token_hex(32))"`. Для запуска без Telegram оставь `OWNER_TELEGRAM_ID=1`, `AUTH_MODE=local` и выключенные уведомления.

```bash
docker compose up --build -d
curl --fail http://127.0.0.1:8000/health
```

Открой `http://127.0.0.1:8000` и введи локальный токен. OpenAPI доступен по `/docs`. Для прямых запросов передай `Authorization: Bearer <LOCAL_API_TOKEN>`. Например, `GET /recurring` возвращает обязательства, `GET /occurrences` — начисления, а `GET /summary?month=2026-11-01` — итоги за месяц.

## Проверки

```bash
docker compose --profile test run --build --rm tests
node --test frontend-tests.mjs
```

Compose поднимает отдельную временную БД для миграций и Python-тестов. При запуске тестов вручную используй изолированную базу с именем, оканчивающимся на `_test`. Тесты очищают её таблицы.
